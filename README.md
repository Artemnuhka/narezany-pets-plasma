# plasma-pets

Тилкайо, Clawd и Codex для KDE Plasma 6 на Wayland. Установи Quickshell, Python 3 и PyGObject, затем запусти `./install.sh` из папки репозитория. Найди **plasma-pets** в меню приложений. Чтобы закрыть программу, нажми правой кнопкой по её значку в трее.

Проект сделан по мотивам ролика narezany в TikTok и не связан с его автором. Спрайты Codex и Clawd принадлежат OpenAI и Anthropic соответственно.
