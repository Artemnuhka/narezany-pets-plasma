# plasma-pets

Тилкайо, Clawd и Codex для KDE Plasma 6 на Wayland.

## Зависимости

- Quickshell
- Python 3
- PyGObject (Gio и GLib)

## Установка

```sh
./install.sh
```

Чтобы закрыть программу, нажми правой кнопкой по её значку в трее.

Проект сделан по мотивам ролика narezany в TikTok и не связан с его автором. Спрайты Codex и Clawd принадлежат OpenAI и Anthropic соответственно.
